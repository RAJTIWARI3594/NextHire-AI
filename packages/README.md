# NextHire AI - Shared Packages Directory

This directory is designated for reusable domain packages, shared UI components, shared TS config, and utility libraries.

## Proposed Modules

- `packages/ui` - Reusable UI component design system.
- `packages/config` - Shared ESLint, Prettier, and TypeScript configurations.
- `packages/types` - Shared data contracts and API DTO definitions.
